# 카 가챠 차고

실차 357종(한국 차 역대 세대 포함)을 뽑아 모으는 웹 자동차 가챠 게임. 지하 주차장 셔터가 올라가며 차가 들어옵니다.

**플레이:** https://cjw030924-art.github.io/car-gacha/

- 1회 뽑기 / 10연차(SR 이상 1대 확정), 60회 SSR 천장, 중복 환급
- 등급 C · R · SR · SSR · UR, 국가·등급별 도감
- 기록은 브라우저(localStorage)에 저장

## 사진 출처

차 사진은 [위키미디어 커먼즈](https://commons.wikimedia.org/)의 자유 라이선스(CC BY / CC BY-SA 등) 사진을 축소해 사용했습니다.
차마다 저작자·라이선스·원본 링크는 [photos.js](photos.js)와 게임 내 상세 화면에 표기되어 있습니다.
커먼즈에 사진이 없는 일부 차(마르샤, 포터 1세대, 포터 II 일렉트릭, SM3 1세대, 다마스)는 사용자가 제공한 사진입니다.
