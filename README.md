# 카 가챠 차고

국산 차를 뽑아 모으는 간단한 웹 자동차 가챠 게임. 지금은 아반떼 8세대만 있고, 차종을 하나씩 늘려 가는 중입니다.

**플레이:** https://cjw030924-art.github.io/car-gacha/

- 1회 뽑기(100코인) / 10연차(1000코인, SR 이상 1대 확정)
- 등급 C · R · SR · SSR, 50회 안에 SSR 확정, 중복은 코인으로 환급
- 차종(아반떼, K3, K5 …)별 도감
- 기록은 브라우저(localStorage)에 저장

## 차 추가하는 법

`index.html`의 `RAW` 목록 맨 아래에 한 줄을 추가하고, `img/키.jpg` 사진을 넣습니다.

```
이름|브랜드|차종|연식|형태(sedan·suv·hatch·coupe·truck·van·mini)|등급(C·R·SR·SSR)|키
기아 K5 (DL3)|기아|K5|2019|sedan|R|k5-dl3
```

차 이미지는 AI로 생성한 그림이며, 이 사이트는 각 제조사와 관련이 없는 팬 프로젝트입니다.
